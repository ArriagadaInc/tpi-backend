### Defense in Depth Funcionando

```
Streamlit (HTML validation)
    ↓ (Rechaza caracteres peligrosos)
Pydantic (Normalización + Type hints)
    ↓ (Valida RUT, email, phone)
Repository (Parametrized queries)
    ↓ (SQL injection prevention)
PostgreSQL (Constraints + Triggers)
    ↓ (Validación en BD)
```

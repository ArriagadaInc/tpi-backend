# H2.5 CEO Validation Guide

## Status

This guide is prepared for the DEV validation. It is not active until DNS,
HTTPS, deployment, and the approved DEV user have been configured.

## Access

The technical team will provide separately:

- the HTTPS DEV URL;
- the approved username;
- a temporary password through a secure channel.

Do not share the temporary password in email, chat, tickets, or documents.

## Validation flow

1. Open the HTTPS DEV URL and confirm it shows the development environment.
2. Enter the supplied username and temporary password.
3. Register one lead using only fictitious information.
4. Confirm the successful registration message and DEV email notification.
5. Find the lead, open its detail, and review the available traceability.
6. Use the explicit DEV test-lead cleanup action to delete the fictitious lead.
7. Confirm the lead no longer appears.
8. Select `Cerrar sesion` and confirm the login screen appears again.

## Safety rules

- Use fictitious information only.
- Do not enter client data, RUTs, real phone numbers, or personal email.
- Report access or application issues to the technical team without sending a
password or screenshot containing credentials.
- The DEV authentication is temporary and DEV-only; it is not the future
production login mechanism.

# H3.3.3 — Matriz de cobertura AC → implementación → pruebas

Control manual de cobertura de requisitos mientras se desarrolla la futura mejora
estructural del Harness. El Reviewer independiente debe usar esta matriz.

Leyenda de estado:

- `cubierto`: existe implementación real y al menos una prueba automatizada que la
  verifica (no se marca sin ambos).
- `implementado`: existe implementación, pero la verificación del criterio es humana
  y queda pendiente de la etapa correspondiente.
- `pendiente`: fuera del alcance del rol Developer (Human Gate / Deployer / Reviewer).
